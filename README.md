
# Python Assignment – Daily Sales Program

## Project Description
This project is a simple Python program that calculates daily sales information.

## Program Features
- Enter daily sales amounts.
- Store sales values in a list.
- Create a dictionary using day numbers and sales amounts.
- Calculate total sales.
- Calculate average sales.
- Find maximum and minimum sales.
- Handle invalid inputs using exception handling.
